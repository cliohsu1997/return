# Academic note prose

Do this for every paragraph, on any topic. If a later step fails, go back.

1. Figure out all of the logic.
2. Put that logic in order.
3. Simplify the logic, and keep the intuition.
4. Write the topic sentence from that.
5. Write the supporting sentences. Each one connects to the one before it, stays concise, and is necessary. Together they are sufficient.
6. Check that every term is defined before it is used. If one is not, the order is wrong. Go back to step 2.
7. Check that the wording is consistent.
8. No semicolons or colons in the prose. Split into separate sentences instead.
9. No dashes to connect sentences. Break long sentences into short ones. Connect them with transitions.
